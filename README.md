## Funcionalidades

- Internacionalização (PT/BR · EN) via sistema de i18n próprio
- Navegação por abas sem reload de página
- Efeito de digitação animado no perfil
- Fundo animado com partículas (dots)
- Seção de projetos com cards e links externos
- Layout responsivo com sidebar recolhível no mobile

## Estrutura

## Rodando localmente

Sem dependências. Só abrir o `index.html` no navegador.
